## 2. Other things worth checking before you commit to a name

RDAP only confirms the domain. Before finalizing, also check:

- **npm package name** (only matters if you ever publish the code as a package): `npm view <name>` — a 404/`npm ERR! 404` means it's free.
- **Social handles** (Instagram/X/Facebook — useful if you'll market to teachers): search the handle manually on each platform; there's no single authoritative API for this.
- **Trademark conflicts**: a quick sanity search on the [USPTO TESS database](https://tmsearch.uspto.gov) (US) and the [India Trademark Registry](https://ipindiaonline.gov.in/tmrpublicsearch/) for the exact name + "education"/"software" category. This is a sanity check, not legal clearance — consult a trademark professional before heavy investment in a brand.

## 3. Registering the domain and connecting it to Vercel

Once you've picked a name:

1. **Register the domain** at a registrar (Namecheap, GoDaddy, Google Domains successor like Squarespace Domains, or India-specific registrars like BigRock/GoDaddy India for `.in`). Price-compare — `.com`/`.app` are usually similarly priced; `.app` requires HTTPS (enforced by Google) which Vercel already provides by default, so that's not a blocker.
2. In your **Vercel project dashboard** → Settings → Domains → Add the domain you registered.
3. Vercel will show you DNS records to add (usually an `A` record pointing to `76.76.21.21` and/or a `CNAME` for `www`, depending on whether you're using the root domain or a subdomain).
4. Go to your registrar's DNS settings and add those exact records.
5. Wait for DNS propagation (usually minutes, can take up to 24-48 hours) — Vercel's dashboard will show the domain as "Valid" once it detects the records.
6. ✅ Done — `package.json`'s `name` field, the `<title>` in `index.html`, the `<h1>` in `App.jsx`, the README, and the "generated by" footer on printed worksheets have all been updated to WorksheetLoom.
7. Remaining manual steps (outside this repo): add `worksheetloom.com` in the Vercel dashboard, point its DNS at Vercel per steps 2-5 above, and once live, replace the placeholder favicon (`public/vite.svg`) with a real WorksheetLoom logo/favicon.
